This paper measures the time required to detect an LLM agent escaping a sandbox. 
Using Sentinel, a containerized harness, we evaluate 416 runs against three independent telemetry signals: 
process liveness, persistent canary tokens, and outbound traffic. 
Our findings reveal that the delivery channel dictates compliance more than content, 
with local knowledge bases yielding a 60 percent follow-through rate compared to 10 percent via network. 
Counterintuitively, applying a production security guardrail triples data leakage, an effect controlled tests confirm is not caused by priming the attack surface. 
Furthermore, we identify a 44-second gap between detection (2.22s) and containment, and document four silent telemetry failures where evaluation components reported success without measuring anything.
