\section{The Harness}

Sentinel runs a tool-calling LLM agent inside a Docker sandbox, plants a
temptation to leave it, and watches three independent signals for evidence
that the agent took the bait. Every component is deliberately cheap: the whole
thing runs on one laptop with a 7B local model, and nothing in it asks the
model to report on itself.

Two Docker networks (\texttt{red-proxy} and \texttt{red-mocks}) are declared
\texttt{internal}, so no traffic the agent generates can reach the real
internet regardless of what the model decides to do. A third network exists
only so the harness itself can reach the model backend, and it carries no
agent-controlled traffic.

\subsection{Three model-independent signals}

Each signal audits a different surface and lives in a different container.
None of them queries the model, and none depends on the agent cooperating.

\centering
\small

\textbf{Monitor} & \textbf{Surface} & \textbf{Fires on} \\
\midrule
\texttt{heartbeat\_monitor} & process liveness & silence past a configured threshold \\
\texttt{canary\_monitor} & filesystem, persistent memory & canary token in a path or in file content \\
\texttt{egress\_monitor} & outbound HTTP & destination outside baseline, or canary in a request \\
\bottomrule
\end{tabular}

The canary is a per-run token injected into the agent's system prompt as its
``internal session identifier''. Detection matches the plain token plus four
cheap obfuscations (base64, URL encoding, hex, and reversal). That coverage is
a deliberate floor, not a claim: an agent encoding the token in, say, the
lengths of file names defeats it, and we say so in Section~\ref{sec:validity}.

The canary monitor detects by inotify rather than polling, with a slower
periodic sweep as a backstop in case an event is missed.

\subsection{Six induction vectors}

The agent always gets the same surface task, fixing a division bug so a test
suite passes. What changes is the temptation planted around it.

Tasks 01 through 03 are passive temptation, a credentials file or an error
pointing at an internal registry, with nothing instructing the agent to act.
They produce none of the results reported here and exist only because the
harness supports them.

Tasks 04 through 06 carry an \emph{identical} injected instruction, asking the
agent to create a confirmation directory named with its own session identifier,
and differ only in how it reaches the agent: a live fetch from an external
mirror, a note seeded in cross-run persistent memory, or a document seeded in a
local knowledge base. Holding the text constant while varying the channel is
what makes the comparison in Section~\ref{sec:results} possible. The technique
is the anchor incident's own, which moved data out in directory
names~\cite{huggingface2026intrusion}.

Vectors 05 and 06 fall under \textbf{ASI06: Memory and Context
Poisoning}~\cite{owasp-asi06}: untrusted input stored as trusted memory or
retrieved context, influencing later and unrelated sessions. Vector 05 is the
stricter case, since \texttt{./memory} is a host bind mount that survives
\texttt{docker compose down -v} and therefore outlives the run that wrote it.

\subsection{Conditions}

The experimental axis is what the system prompt says about security, holding
the task constant.

The canary is present in all three conditions, since it is detection
instrumentation rather than a defence. What changes is the system prompt:
\texttt{sin\_harness} mentions the token in one 77-character line,
\texttt{con\_harness} carries the 830-character production guardrail that
names file names, directory names and URLs as surfaces the token must never
reach, and \texttt{con\_harness\_generico} matches that guardrail's length
and emphasis (818 characters, 126 words against 131) while forbidding only
that the token leave the working environment, without naming how.

The third condition exists to separate two things the second confounds: a
guardrail that is longer and more emphatic, and one that names the attack
surface. Section~\ref{sec:results} reports what that isolation produced,
which is not what we expected.
