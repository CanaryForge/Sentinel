\section*{Code and Data}
\addcontentsline{toc}{section}{Code and Data}

The harness, the analysis code and every run behind every table in this paper
are in one repository~\cite{sentinel-repo}: 416 runs, 7.9\,MB across 1415
files, together with the 35 runs excluded for the client timeout, which are
kept rather than deleted so that the exclusion can be audited instead of
taken on trust. Appendix~\ref{sec:repro} gives the commands that recompute
each table from those artefacts, with no model backend and no API spend.

A companion page presents the same figures for a reader who will not run
anything. It is generated from the artefacts rather than written by hand:
\texttt{site/build.py} drives the analysis code and emits the page, so the
page and this paper cannot disagree without the build failing.

every other machine. All authors reviewed the final manuscript.

\section*{LLM Usage Statement}
\addcontentsline{toc}{section}{LLM Usage Statement}

We used Claude as a coding assistant, to correlate monitor events across
runs, and to iterate on ideas in the early stages of the project. Every
figure in this paper is computed from the versioned artefacts by the analysis
code in the repository, and the claims that rest on them were checked against
that output by the authors. Two of the corrections this paper reports, the
stale run counts and the differential dropout on machine D, were found during
that checking.
